# HSBC-Personal-Loan-Acceptance-Analysis
# HSBC Personal Loan Acceptance Analysis & Dashboard

## Project Overview

This project focuses on analyzing HSBC customer data to identify the major factors influencing personal loan acceptance. The goal of the analysis was to help HSBC improve marketing campaign efficiency by targeting customers who are more likely to accept loan offers.

The project was completed entirely in **Microsoft Excel** using data analysis, visualization, and dashboarding techniques.

---

# Objectives

* Perform Exploratory Data Analysis (EDA)
* Identify customer segments with high loan acceptance rates
* Analyze customer financial behavior
* Build an interactive Excel dashboard
* Generate business insights and recommendations

---

# Tools & Techniques Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* KPI Cards
* Slicers & Filters
* Conditional Formatting
* Dashboard Design

---

# Key Insights

* High-income customers showed significantly higher loan acceptance rates.
* Graduate & Professional customers were more likely to accept loans.
* TD Account holders demonstrated very strong conversion rates.
* Customers with high monthly credit card spending (CCAvg) showed higher borrowing behavior.
* Online banking usage and credit card ownership alone had weak influence on loan acceptance.

---

# Dashboard Features

* KPI Summary Cards
* Income-wise Loan Acceptance Analysis
* Education Analysis
* Mortgage Analysis
* CCAvg Analysis
* TD Account Analysis
* Interactive Slicers & Filters

---

# Business Recommendations

* Prioritize high-income customer segments
* Target Graduate & Professional customers
* Focus on TD Account holders for cross-selling opportunities
* Use customer spending behavior for campaign targeting
* Reduce marketing efforts toward low-conversion customer groups

---

# Project Outcome

The analysis helped identify the strongest predictors of personal loan acceptance and provided data-driven recommendations to improve HSBC’s marketing strategy, campaign efficiency, and customer targeting.

Several pivot tables later, banking analytics once again confirmed that targeting financially capable customers works better than emailing the entire population like a desperate festival flyer campaign.
